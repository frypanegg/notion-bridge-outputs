🏠 노션 브릿지 코딩 사용 설명서

노션 댓글로 집 맥미니의 Claude Code에게 코딩을 시키는 방법

📌 한눈에 보기

이 시스템은 노션 페이지의 댓글창을 채팅창처럼 사용해서, 집에 있는 맥미니의 Claude Code(코딩 AI)에게 작업을 시키는 도구입니다. 노션 데이터베이스의 각 행(row)이 하나의 "대화 세션"이 되고, 그 세션 페이지에 댓글을 달면 15초 안에 맥미니가 읽어서 작업을 시작합니다.

Notion (무료 플랜) 맥미니 ┌──────────────────────────────┐ 15초 폴링 ┌─────────────────────────────────┐ │ Claude Code DB = 세션 목록 │<────────────►│ nbc bridge (상시 실행) │ │ 🟢/🟠/🔴 아이콘 = 상태 표시 │ │ 1. 새 댓글 감지 (허용된 사람만) │ │ │ │ 2. /명령 은 로컬 처리 (토큰 0) │ │ 세션 페이지 │ │ 3. Claude Code 실행 │ │ 본문 = 대화 기록 │<──────────────┤ 4. 결과물 → 구글 드라이브 업로드 │ │ 댓글 = 입력창 / 답장 │<──────────────┤ 5. 요약 + 링크를 댓글로 답장 │ └──────────────────────────────┘ └─────────────────────────────────┘

💬 사용하는 방법 (사용자 입장)

1
세션 페이지 열기 — "Claude Code" 데이터베이스에서 작업할 세션(페이지)을 하나 고르거나 새로 만듭니다.
2
댓글로 요청 작성 — 페이지 아래 댓글창에 원하는 작업을 자연어로 적습니다. 예: "이 파일에 로그인 기능 추가해줘"
3
15초~수분 대기 — 맥미니가 자동으로 댓글을 읽고 Claude Code를 실행합니다. 작업 중에는 상태 아이콘이 🟠로 바뀝니다.
4
답장 확인 — 같은 댓글 스레드에 요약과 결과물 링크(구글 드라이브)가 달립니다. 완료되면 상태가 🟢로 바뀝니다.
⚠️ 허용된 사람의 댓글만 처리됩니다. 아무나 댓글을 달아도 무시되니 안심하세요.

⚡ 슬래시 명령 (AI를 부르지 않는 빠른 명령)

아래 명령들은 Claude를 실행하지 않고 즉시 처리되어 토큰(비용)이 들지 않습니다.

명령기능
/modelopus / fable / sonnet / haiku 중 사용할 AI 모델 변경
/effortlow ~ max, 생각을 얼마나 깊게 할지 조절
/usage현재까지 사용량(플랜 한도) 확인
/new대화 새로 시작 (이전 맥락 초기화)
/stop진행 중인 작업 중지
/status현재 세션 상태 확인

특정 요청 하나만 다른 모델로 실행하고 싶다면 댓글 맨 앞에 @haiku처럼 붙이면 됩니다.

🔧 결과물은 어디서 보나요?

Claude가 만든 파일(코드, 문서, 이미지 등)은 자동으로 구글 드라이브에 업로드되고, 답장 댓글에 링크 하나로 정리되어 옵니다. 소스 코드가 바뀐 경우 변경 내역(patch)도 같은 폴더에 함께 저장됩니다.

🛠 (관리자용) 초기 설정 요약

이 부분은 시스템을 처음 설치·설정하는 사람만 참고하면 됩니다.

1
노션 integration에서 댓글 읽기/쓰기 권한 켜기 + 세션 DB에 연결
2
rclone config로 구글 드라이브 연결
3
맥미니에서 claude 명령으로 Claude Code 로그인
4
bridge.config.json 설정 후 아래 명령 실행
npm run dev -- bridge-setup <세션 DB URL>
npm run dev -- bridge          # 상시 실행 시작

맥미니를 항상 켜두려면: sudo pmset -a sleep 0 disksleep 0
