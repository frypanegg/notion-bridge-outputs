## 요청

> 패러다임 변화를 위한 4개의 축에서 '관리 주체'를 하나 추가해줘. PPT 수정하지 않고, 나에게 PPT에 들어갈 객체를 이미지 형태로 보여줘.
> As-Is는 인사부서 주도 하에서 인력 감축 노력 중이나,
> To-be는 인력 운영 부서장이 경여적 마인드로 적정 노무비 내에서 인력 운영할 수 있도록 재량, 권한, 책임을 확대하겠다.는 내용으로

## 요약

PPT는 그대로 두고 Ⅰ장 '인력운영 패러다임 전환'에 넣을 ⑤ '관리 주체' 축을 기존 4개 축과 같은 디자인의 이미지(SVG) 2개로 만들었습니다. 하나는 이 축만 따로 그린 것이고, 다른 하나는 5개 축을 모두 배치해 본 미리보기입니다.
문구는 As-Is '인사부서 주도下 인력 감축 노력' → To-Be '인력운영 부서장 책임경영 / 적정 노무비 內 자율 운영 / 재량·권한·책임 확대'입니다. 요청하신 '경영적 마인드'는 '책임경영'이라는 말로 담았습니다.
장표는 행이 짝으로 되어 있어 왼쪽 '여건 변화'에도 ⑤ 카드가 필요합니다. 그래서 '인사부서 주도 인력 감축의 실행력 한계' 카드를 제가 임의로 만들어 '(참고안)'으로 표시했습니다. 내용을 확인해 주세요.
5개 축을 한 장에 넣으면 행 높이가 1.0→0.8in로 줄고, 본문 글자도 8.5→8pt로 작아집니다.
PNG로 바꾸는 명령(qlmanage, sips)은 승인이 필요해 실행하지 못했습니다. 그래서 파일은 SVG뿐이고, 렌더링 결과를 제 눈으로는 확인하지 못했습니다. SVG는 브라우저에서 바로 볼 수 있고, PPT에서는 삽입 > 그림으로 넣은 뒤 '도형으로 변환'하면 편집할 수 있습니다.
